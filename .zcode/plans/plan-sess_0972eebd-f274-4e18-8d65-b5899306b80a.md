## G5 — Web API & WebSocket Contract

### New File: `components/web_server/web_device_settings_api.c`

Three endpoints following existing patterns (`web_send_json`, `web_send_api_error_code`, `web_parse_request_json`):

**1. `GET /api/devices/settings?device_id=X`**
- Acquire schema + values snapshots via `device_settings_schema_acquire()` / `device_settings_values_acquire()`
- Build JSON with settings array (type-mapped, secret redacted to `{"id":..., "type":"secret", "configured":bool}`)
- Release snapshots on every return path
- Errors: 400 (missing device_id), 404 (device/setting not found), 503 (offline/unsupported)

**2. `PUT /api/devices/settings`**
- Parse JSON body (`device_id`, `expected_revision`, `changes[]`)
- Map changes to `ds_change_request_t[]`, call `device_settings_save()`
- Return 202 `{"operation_id": device_id, "state": "queued"}`
- Errors: 400 (malformed), 409 (active transaction), 422 (validation), 503 (offline)

**3. `GET /api/devices/settings/operations?device_id=X`**
- Check `ds_tx_find()` for active tx + static result registry for last completed
- Return `{"active":bool, "state":"...", "config_revision":N, "error":null|"..."}`
